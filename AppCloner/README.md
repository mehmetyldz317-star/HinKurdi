# Ayrı Alan v1

Android'in managed/work profile özelliğini kullanarak ana profilden ayrı uygulama verisi ve oturum alanı oluşturur.

- Paket: com.naturel.ayrialan
- minSdk: 26
- targetSdk: 35
- Reklam yok
- Ayrı profil kurulumu Android sistem ekranı üzerinden yapılır.
- Profil içinde Play Store'dan uygulama kurulduğunda ana profilden bağımsız veri/oturum tutulur.

Not: Android'in herkese açık API'leri sınırsız sayıda work profile oluşturulmasına izin vermez. Bu sürüm bir adet ek izole profil sağlar.
